# Example: How NGO Creates a Campaign Report

## Scenario
**NGO**: "Help Children Foundation"
**Campaign**: "Winter Clothing Drive for Street Children"
**Funds Raised**: ₹50,000
**Goal**: Create a utilization report showing how funds were spent

## Step-by-Step Process

### 1. Access Report Creation
- NGO logs into dashboard
- Clicks "Campaign Reports" → "Create Report"

### 2. Fill Basic Information
```
Campaign: Winter Clothing Drive for Street Children
Report Type: Fund Utilization
Title: "Winter Clothing Distribution Report - January 2025"
Description: "This report details how the ₹50,000 raised was utilized to purchase and distribute winter clothing to 200 street children in Delhi."
```

### 3. Utilization Details
```
Amount Utilized: ₹45,000
```

### 4. Expense Breakdown
**Expense 1:**
- Category: "Winter Jackets"
- Amount: ₹25,000
- Description: "Purchased 100 winter jackets at ₹250 each for children aged 8-15"
- Bills: Upload photos of purchase receipts from clothing vendors

**Expense 2:**
- Category: "Blankets"
- Amount: ₹12,000
- Description: "Bought 120 blankets at ₹100 each for distribution"
- Bills: Upload invoice from blanket supplier

**Expense 3:**
- Category: "Transportation"
- Amount: ₹5,000
- Description: "Vehicle costs for distribution to 5 different locations"
- Bills: Upload fuel receipts and vehicle rental bills

**Expense 4:**
- Category: "Administrative"
- Amount: ₹3,000
- Description: "Documentation, photography, and volunteer coordination"
- Bills: Upload receipts for printing, photography equipment

### 5. Additional Information
```
Achievements: 
"Successfully distributed winter clothing to 200 children across 5 locations in Delhi. All children received jackets and blankets. Organized distribution events with local volunteers."

Challenges: 
"Weather conditions made distribution difficult on some days. Some remote locations were hard to access. Need better coordination with local authorities."

Next Steps: 
"Planning summer clothing drive for April 2025. Will use remaining ₹5,000 as seed funding. Seeking partnerships with more local organizations."
```

### 6. Publishing Decision
- ✅ **Publish Immediately** (for transparency)
- This makes the report visible on the campaign's public page

### 7. Result
- Report appears in NGO's reports dashboard
- Donors can view it on `/campaigns/[id]/reports`
- Builds trust and transparency
- Encourages future donations

## What Donors See
When donors visit the campaign page, they see:
- "View Transparency Reports" button
- Detailed expense breakdown with actual bills/receipts
- Clickable bill images and PDFs for verification
- Photos and documentation
- Clear accountability of fund usage with proof

## Benefits for NGO
- Builds donor trust
- Shows professional management
- Encourages repeat donations
- Demonstrates impact clearly
- Meets transparency standards
